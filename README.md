# SaaStudio Website

A fully‑featured single‑page application built in pure HTML/CSS/JavaScript.  It showcases a SaaS product with a marketing front‑end and a simple simulated dashboard.

## Features

- Responsive design for desktop & mobile
- One‑page navigation with section scrolling
- Dashboard modal sections (analytics, users, settings)
- 3‑step signup & login modals
- Demo data for API examples (charts, tables)
- Simple build scripts in `app.js`

## Getting Started

```bash
# serve locally
yarn install
# or if you have npm
npm install

npm start   # opens index.html in default browser
```

> Warning: this repo is a demo; data is static and not connected to a backend.
